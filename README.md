# FACEIT Clone — Веб-приложение на React

## 1. Общая информация

**Название проекта:** FACEIT Clone (клон платформы FACEIT)  
**Тип проекта:** Игровая платформа / Спортивный сервис (клон faceit.com)  
**Цель проекта:**  
Разработка клиентской части современного веб-приложения с использованием библиотеки React. Проект демонстрирует навыки адаптивной верстки, работы с компонентной архитектурой, управления состоянием и взаимодействия с API. Клон повторяет ключевой функционал и дизайн оригинального сайта faceit.com.

**Срок выполнения:** 2 недели активной работы

### Обязательные технологии

## 3. Функциональные требования

### 3.1. Общие страницы
- **Главная страница** — лендинг с ключевыми разделами платформы
- **Страница списка сущностей** — список матчей/турниров/игроков
- **Детальная страница** — информация о матче/турнире/пользователе
- **Страница авторизации** — UI формы входа (без реальной аутентификации)
- **Навигация** — между всеми страницами через React Router
- **Обработка состояний** — loading и error states
- **Адаптивная верстка** — desktop + mobile

### 3.2. Специфичный функционал (FACEIT)
- Каталог матчей/турниров
- Фильтрация игр (CS2, Dota 2, Valorant и др.)
- Лига/ранговая система (визуализация)
- Имитация оформления участия в турнире

## 9. Запуск проекта

### Предварительные требования
- Node.js ≥ 16.x
- npm или yarn

### Установка
```bash
# Клонировать репозиторий
git clone https://github.com/ваш-ник/faceit-clone.git

# Перейти в директорию
cd faceit-clone

# Установить зависимости
npm install
# или
yarn install
```

### Запуск в режиме разработки
```bash
npm start
# или
yarn start
```

Приложение откроется по адресу: `http://localhost:3000`

### Сборка для продакшена
```bash
npm run build
# или
yarn build
```
